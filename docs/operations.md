# 실행·접속 안내 (개인 사용 단계)

본인 1명이 본인 기기로만 쓰는 단계의 운영 방법입니다. 보안 범위와 감수하는 위험은 `design.md` 7.3에 있습니다.

> 2~4번(설치·실행·로그인)은 개발 중 임시 폴더에 설치해 서버 동작을 확인했습니다. 가입·로그인·비밀번호 변경 화면도 브라우저에서 확인했습니다. 다만 "실행하면 화면이 자동으로 열리는 것"은 자동 테스트로만 확인했습니다.
> **5번(Tailscale)과 6번(홈 화면 추가)은 이 문서를 쓴 환경에 Tailscale·휴대폰이 없어 직접 확인하지 못한 절차입니다.**
> Tailscale 명령 형식은 버전에 따라 다를 수 있으니, 안 되면 `tailscale serve --help`와 Tailscale 공식 문서를 확인하세요.

## 1. 구성 한눈에 보기

```
[휴대폰·다른 PC] --Tailscale(본인 기기만)·HTTPS--> [이 PC] tailscale serve --> 앱 (127.0.0.1:5137)
```

- 앱은 이 PC 안에서만 접속을 받습니다. 다른 기기는 Tailscale을 거쳐야만 들어옵니다.
- 볼 때는 이 PC와 앱이 켜져 있어야 합니다.
- 설치 폴더: 저장소 폴더 옆의 `Portfolio` (저장소가 `D:\Program\Stock_Manager`면 `D:\Program\Portfolio`). 실행 파일은 `app\`, 데이터는 `data\`에 있습니다. 사용자 프로필(C 드라이브)에는 아무것도 두지 않습니다.
- 다른 위치에 설치하려면 `scripts\install.ps1 -InstallRoot "원하는 경로"`로 실행합니다.

| `data\` 안의 파일·폴더 | 내용 |
| --- | --- |
| `portfolio.db` | 실제 보유 내역 |
| `settings.json` | KIS 키 (평문). 첫 실행 때 값이 빈 채로 만들어집니다 |
| `keys\` | 접근토큰 암호화 키 |
| `backups\` | 날짜별 DB 백업 (최근 14일분) |

## 2. 설치와 가입 (처음 한 번)

1. `scripts\install.cmd`를 더블클릭합니다. 실행 파일을 만들어 설치 폴더의 `app\`에 넣고, 바탕화면에 **포트폴리오** 바로가기를 만듭니다. 처음에는 몇 분 걸립니다.
2. 바탕화면의 **포트폴리오** 아이콘을 더블클릭합니다.
3. 처음이면 화면에 가입 화면이 뜹니다. 아이디(3~30자)와 비밀번호(8자 이상)를 정하면 바로 시작됩니다.

계정은 하나만 만들 수 있고, 먼저 접속한 기기가 계정을 만듭니다. **설치하면 다른 기기에 열기 전에 이 PC에서 먼저 가입해 두세요.**
다른 PC와 휴대폰에서는 같은 아이디·비밀번호로 로그인합니다. 여러 기기에서 동시에 로그인해 둘 수 있습니다.

- 앱을 고친 뒤(코드 갱신 후)에는 앱을 끄고 `install.cmd`를 다시 실행하면 새 버전으로 바뀝니다. 데이터는 그대로입니다.
- 비밀번호 변경은 설정 화면의 '비밀번호 변경'에서 합니다 (현재 비밀번호 필요).
- 비밀번호를 바꾸면 바꾼 기기는 그대로 유지되고, 다른 기기는 모두 다시 로그인해야 합니다.
- 비밀번호를 잊었으면 앱을 끄고 이 PC에서 `scripts\set-password.cmd`로 다시 정합니다 (현재 비밀번호를 묻지 않으므로 이 PC에서만 실행됩니다).
- 실행 파일은 .NET이 설치되지 않은 PC에서도 돌아가도록 필요한 것을 모두 담고 있어 크기가 약 105MB입니다.

## 3. KIS 키 넣기 (키를 발급받은 뒤)

1. 앱을 한 번 실행하면 설치 폴더의 `data\settings.json`이 생깁니다.
2. 메모장으로 열어 `AppKey`, `AppSecret` 값을 넣고 저장합니다. 모의투자 키면 `Environment`를 `Mock`으로 바꿉니다.
3. 앱을 다시 실행합니다.

키가 없으면 앱은 켜지지만 시세가 들어오지 않습니다(상단에 '시세 없음').
이 파일은 저장소 밖에 있어 커밋되지 않습니다. 저장소 폴더로 복사하지 마세요.

## 4. 실행

바탕화면의 **포트폴리오** 아이콘을 더블클릭합니다.

- 검은 창이 뜨고, 화면이 주소창 없는 앱 창으로 자동으로 열립니다. (Edge가 없으면 기본 브라우저로 열립니다.)
- **검은 창을 닫으면 앱이 꺼집니다.** 화면 창만 닫으면 앱은 계속 켜져 있어 휴대폰에서 접속할 수 있습니다.
- 이미 켜져 있을 때 아이콘을 다시 더블클릭하면 화면만 다시 열립니다.
- 주소를 직접 열 수도 있습니다: http://127.0.0.1:5137
- 설치하지 않고 저장소에서 바로 실행하려면 `scripts\run.cmd`를 씁니다 (.NET SDK 필요).
- 로그인 후 90일 동안 유지됩니다. 로그아웃은 설정 화면에 있습니다.
- 5번 틀리면 1분 동안 로그인이 막힙니다.

### 오늘 등락과 종목 정보 보기

- 대시보드와 보유 종목 화면의 표에서 **오늘** 열이 전일 종가 대비 등락률입니다. 대시보드의 '오늘 손익'은 오늘 하루 계좌가 얼마 오르내렸는지입니다.
- 메뉴의 **종목 검색**에서 종목을 찾아 현재가, 52주 최고·최저, PER 등을 봅니다. 표의 종목명을 눌러도 그 종목의 정보로 갑니다. 보유하지 않은 종목도 볼 수 있습니다.
- 종목 정보는 화면을 열 때와 '새로 고침'을 누를 때 조회합니다. KIS 키가 있어야 합니다.

### 화면 언어 바꾸기

- **설정** 화면의 '언어'에서 `한국어` 또는 `English`를 고릅니다. 로그인 화면 아래에서도 고를 수 있습니다.
- 고른 언어는 브라우저마다 기억합니다. PC와 휴대폰에서 서로 다른 언어로 볼 수 있습니다.
- 계좌 이름, 그룹 이름, 종목명은 입력된 그대로 보입니다. 영어로 보고 싶으면 그룹 관리와 설정에서 이름을 바꾸세요.

### 어두운 화면으로 보기

- **설정** 화면의 '화면 모드'에서 `시스템 설정 따르기`, `밝게`, `어둡게` 중 하나를 고릅니다.
- 처음에는 '시스템 설정 따르기'입니다. Windows나 휴대폰이 어두운 모드면 앱도 어둡게 나옵니다.
- 고른 모드는 브라우저마다 기억합니다.

### 계좌 여러 개 쓰기

- 상단 바의 계좌 선택 상자에서 볼 계좌를 고릅니다. 보유 종목·그룹·목표 비중·예수금·리밸런싱 계산이 모두 고른 계좌 기준으로 바뀝니다. 고른 계좌는 브라우저마다 기억합니다.
- 계좌 추가·이름 변경·순서 변경·삭제는 **설정** 화면의 '계좌'에서 합니다. 새 계좌는 주식 50 / 채권 30 / 배당 20 그룹으로 시작합니다.
- 계좌를 삭제하면 그 계좌의 보유 종목·그룹·예수금이 함께 지워지고 되돌릴 수 없습니다. 실수했으면 7번의 백업으로 복원합니다.
- 계좌번호는 입력받지도 저장하지도 않습니다. 이름만 구분용으로 씁니다.
- 계좌 기능이 생기기 전에 넣어 둔 종목은 업데이트 후 처음 켤 때 'ISA' 계좌로 자동으로 옮겨집니다.

## 5. 휴대폰·다른 PC에서 접속 (Tailscale)

1. 이 PC, 휴대폰, 다른 PC에 Tailscale을 설치하고 **같은 계정**으로 로그인합니다.
2. Tailscale 관리 화면(admin console)에서 MagicDNS와 HTTPS 인증서 기능을 켭니다.
3. 이 PC에서 앱을 실행한 상태로 터미널에 입력합니다.

   ```
   tailscale serve --bg 5137
   ```

4. 명령이 알려 주는 주소(`https://<PC이름>.<tailnet이름>.ts.net`)로 휴대폰·다른 PC에서 접속합니다.
5. 끄려면 `tailscale serve reset`.

**하지 말 것**

- `tailscale funnel` — 인터넷 전체에 공개됩니다. 지금 로그인(아이디·비밀번호만, 누구나 가입 화면 접근 가능)은 그 용도로 충분하지 않습니다.
- 공유기 포트포워딩, `--urls http://0.0.0.0:...`로 실행 — 같은 네트워크의 모든 기기에 열립니다. 이렇게 띄우면 앱이 경고를 남깁니다.

## 6. 휴대폰 홈 화면에 추가

5번 주소로 접속해 로그인한 뒤:

- iPhone (Safari): 공유 버튼 → '홈 화면에 추가'
- Android (Chrome): 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'

홈 화면의 '포트폴리오' 아이콘으로 열면 주소창 없이 전체 화면으로 열립니다.

## 7. 백업과 복원

- 앱을 켠 날마다 `backups\portfolio-YYYYMMDD.db`가 하나씩 생기고, 최근 14개만 남습니다.
- 같은 디스크에 있으므로 디스크 고장에는 대비가 안 됩니다. 가끔 `backups` 폴더를 다른 드라이브나 USB에 복사해 두세요.
- 복원: 앱을 끄고, 되돌릴 날짜의 백업 파일을 `portfolio.db` 이름으로 덮어쓴 뒤 다시 실행합니다. (덮어쓰기 전에 현재 `portfolio.db`를 다른 이름으로 복사해 두세요.)

## 8. 문제가 생겼을 때

| 상황 | 조치 |
| --- | --- |
| 비밀번호를 잊음 | 이 PC에서 `scripts\set-password.cmd`로 새로 설정 |
| 휴대폰을 잃어버림 | Tailscale 관리 화면에서 그 기기를 삭제하고, 설정 화면에서 비밀번호를 바꿈 (다른 기기는 모두 로그아웃됨) |
| 시세가 안 들어옴 | 상단 바가 '시세 없음'이면 `settings.json`의 키 확인. 실행 창에 'KIS … 설정되지 않아' 경고가 있는지 확인 |
| 다른 기기에서 안 열림 | 이 PC와 앱이 켜져 있는지, `tailscale serve status`에 5137이 보이는지, 접속 기기의 Tailscale이 켜져 있는지 확인 |

## 9. 개발용 실행 (가짜 시세)

실제 데이터와 무관하게 화면만 볼 때 씁니다. 로그인 없이 열리고, 저장소 폴더의 `Portfolio.Web/portfolio.dev.db`에 가상 시드 데이터가 들어갑니다.

```
dotnet run --project Portfolio.Web --launch-profile http
```
